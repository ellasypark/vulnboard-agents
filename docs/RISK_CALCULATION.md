# 위험도 계산 로직 상세 가이드 (v3.0)

## 🎯 개요

WAF 대시보드의 위험도는 실제 로그 데이터를 기반으로 **다층 분석(Multi-layer Analysis)**을 통해 계산됩니다.

## 🔄 v3.0 주요 변경사항

### 1. 버그 수정
- **음수 점수 버그 해결**: 개별 룰 점수가 음수로 나오는 치명적인 버그 수정
- **방어 로직 추가**: 모든 계산 단계에서 음수 방어 및 검증 로직 추가
- **소수점 처리**: 소수점 첫째 자리로 반올림하여 깔끔한 표시

### 2. UI 개선
- **타이틀 변경**: "실시간 위험도" → "종합 시스템 위험도"
- 더 포괄적이고 정확한 의미 전달

### 3. 동적 위험도 산정
- **최고 위험도 동적 계산**: 적용된 룰셋 상태에 따라 50~100점 사이에서 동적 결정
- **최저 위험도 고정**: AI 추천 룰이 남아있는 한 항상 50점으로 고정
- **보안 노력 반영**: 사용자의 보안 조치가 위험도에 즉시 반영

## 📊 계산 방식

### 1. 기준 위험도 계산 (100점 만점)

보안 룰이 전혀 없는 상태의 위험도를 계산합니다.

#### 1-1. 위험도 레벨별 분류 (40점 만점)

로그의 `risk_score`를 기준으로 5단계로 분류:

| 레벨 | risk_score 범위 | 가중치 |
|------|----------------|--------|
| 치명적 (Critical) | 85 이상 | 40점 |
| 높음 (High) | 70~84 | 30점 |
| 중간 (Medium) | 40~69 | 20점 |
| 낮음 (Low) | 20~39 | 10점 |
| 최소 (Minimal) | 20 미만 | 0점 |

**계산식:**
```
level_score = (critical_logs / total_logs × 40) +
              (high_risk_logs / total_logs × 30) +
              (medium_risk_logs / total_logs × 20) +
              (low_risk_logs / total_logs × 10)
```

#### 1-2. WAF 액션별 분류 (30점 만점)

WAF가 취한 액션을 기준으로 분류:

| 액션 | 의미 | 가중치 |
|------|------|--------|
| BLOCK | 차단됨 (위험 높음) | 30점 |
| COUNT | 카운트만 (잠재적 위험) | 20점 |
| ALLOW | 허용됨 (위험 낮음) | 5점 |

**계산식:**
```
action_score = (blocked_logs / total_logs × 30) +
               (count_logs / total_logs × 20) +
               (allowed_logs / total_logs × 5)
```

#### 1-3. 공격 비율 (30점 만점)

정상 트래픽을 제외한 실제 공격 로그 비율:

**제외 대상:**
- Normal Traffic
- Allowed Traffic
- Debug Resource Request

**계산식:**
```
attack_ratio = attack_logs / total_logs
attack_score = attack_ratio × 30
```

#### 1-4. 기준 위험도
```
base_risk = level_score + action_score + attack_score
base_risk = max(50, min(100, base_risk))  // 50~100점 범위 제한
```

---

### 2. 최고 위험도 동적 계산 (50~100점)

**핵심 개선**: 적용된 룰셋의 상태에 따라 동적으로 계산됩니다.

#### 계산 로직

```
max_risk = base_risk - (적용된 룰들의 보호 효과 합계)
max_risk = max(50, min(100, max_risk))
```

#### 시나리오별 예시

| 상황 | 기준 위험도 | 적용된 룰 | 최고 위험도 |
|------|------------|----------|------------|
| 초기 상태 (룰 없음) | 85점 | 0개 | 85점 |
| 일부 적용 | 85점 | 3개 (20점 감소) | 65점 |
| 대부분 적용 | 85점 | 7개 (35점 감소) | 50점 |

**중요**: 최고 위험도는 절대 50점 아래로 내려가지 않습니다.

---

### 3. 최저 위험도 (고정 50점)

모든 AI 추천 룰을 적용했을 때 도달 가능한 최소 위험도입니다.

**고정값**: 50점

**이유**:
- AI 추천 룰이 남아있는 한 완전히 안전한 상태는 아님
- 추가 보안 조치가 필요함을 명확히 표시
- 사용자에게 지속적인 보안 개선 동기 부여

---

### 4. 룰별 위험도 감소 점수 (음수 방어 강화)

각 AI 추천 룰이 위험도를 얼마나 낮출 수 있는지 계산합니다.

#### 중요도 계산

```
importance = (WCU 가중치 × 0.5) +
             (탐지 건수 가중치 × 0.3) +
             (차단 건수 가중치 × 0.2)
```

**가중치 계산:**
- WCU 가중치: `rule.wcu / total_wcu`
- 탐지 건수 가중치: `rule.detections / total_logs`
- 차단 건수 가중치: `rule.blocked / total_blocked`

#### 감소 점수 계산 (음수 방어)

```
total_reduction = max_risk - min_risk
normalized_importance = importance / total_importance
rule_reduction = total_reduction × normalized_importance

// 음수 방어
rule_reduction = max(rule_reduction, 0.0)
// 소수점 첫째 자리로 반올림
rule_reduction = round(rule_reduction, 1)
```

**방어 로직**:
1. `total_reduction <= 0`인 경우: 모든 룰의 감소 점수를 0으로 설정
2. `total_importance == 0`인 경우: 균등 분배
3. 모든 계산 결과에 `max(value, 0)` 적용

---

### 5. 실시간 위험도 업데이트

#### 룰 적용 시 (뺄셈)
```
reduction = max(riskReductionMap[rule_id], 0)  // 음수 방어
new_risk = currentRisk - reduction
current_risk = max(new_risk, min_risk)  // 최저 위험도 이하로 내려가지 않음
current_risk = round(current_risk, 1)  // 소수점 첫째 자리
```

#### 룰 제거 시 (덧셈)
```
reduction = max(riskReductionMap[rule_id], 0)  // 음수 방어
new_risk = currentRisk + reduction
current_risk = min(new_risk, max_risk)  // 최고 위험도 이상으로 올라가지 않음
current_risk = round(current_risk, 1)  // 소수점 첫째 자리
```

## 📈 계산 예시

### 시나리오
- **총 로그**: 1000개
- **치명적 로그**: 50개 (5%)
- **높은 위험 로그**: 150개 (15%)
- **중간 위험 로그**: 300개 (30%)
- **낮은 위험 로그**: 200개 (20%)
- **차단된 로그**: 200개 (20%)
- **카운트 로그**: 300개 (30%)
- **허용된 로그**: 500개 (50%)
- **공격 로그**: 600개 (60%)
- **총 WCU**: 1528

### 계산 과정

#### 1. 레벨 점수 (40점 만점)
```
level_score = (50/1000 × 40) + (150/1000 × 30) + (300/1000 × 20) + (200/1000 × 10)
            = 2.0 + 4.5 + 6.0 + 2.0
            = 14.5점
```

#### 2. 액션 점수 (30점 만점)
```
action_score = (200/1000 × 30) + (300/1000 × 20) + (500/1000 × 5)
             = 6.0 + 6.0 + 2.5
             = 14.5점
```

#### 3. 공격 점수 (30점 만점)
```
attack_ratio = 600/1000 = 0.6
attack_score = 0.6 × 30 = 18.0점
```

#### 4. 기준 위험도
```
base_risk = 14.5 + 14.5 + 18.0 = 47점
base_risk = max(50, 47) = 50점  // 최소 50점 보장
```

#### 5. 최고 위험도 (초기 상태)
```
max_risk = 50점  // 아무 룰도 적용 안 함
```

#### 6. 최저 위험도
```
min_risk = 50점  // 고정값
```

#### 7. 감소 가능 범위
```
total_reduction = 50 - 50 = 0점
```

**주의**: 이 경우 기준 위험도가 이미 최소값(50점)이므로 추가 감소 불가

## ⚠️ 주의사항

1. **로그가 없는 경우**
   - 기본값: max_risk = 85, min_risk = 50
   - calculation_method = "default (no logs)"

2. **위험도 범위**
   - 최소: 50점 (AI 추천 룰이 남아있는 한)
   - 최대: 100점 (보안 룰이 전혀 없는 최악의 상태)

3. **최저 위험도 고정**
   - 최저 위험도는 항상 50점으로 고정
   - 모든 AI 룰을 적용해도 50점까지만 감소

4. **음수 방어**
   - 모든 계산 단계에서 `max(value, 0)` 적용
   - 소수점 첫째 자리로 반올림 (`round(value, 1)`)

5. **실시간 업데이트**
   - 룰 적용/제거 시 즉시 반영
   - 페이지 새로고침 시 초기값으로 리셋
