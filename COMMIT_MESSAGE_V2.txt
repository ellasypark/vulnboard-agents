fix: 위험도 범위 조정 및 WAF 룰 태그 색상 도넛 그래프와 완전 통일

문제점 1: 위험도 범위
- 기존: 20~95점 범위
- 문제: 최소 20점은 너무 낮아서 위험도 체감이 어려움
- 요구사항: 최소 50점 이상으로 설정 필요

문제점 2: 태그 색상 불일치
- WAF 룰 태그 색상이 도넛 그래프(월별 공격 유형)와 다름
- 사용자 혼란 및 일관성 부족

개선사항:

1. 위험도 범위 조정 (50~100점)
   - 최소: 50점 (WAF 룰이 없으면 기본적으로 위험함)
   - 최대: 100점 (최악의 상태)
   - 합리적인 위험도 체감 가능

2. WAF 룰 태그 색상 완전 통일
   - 카테고리 → 공격 유형 매핑 로직 개선
   - 도넛 그래프의 색상 코드를 그대로 사용
   - 개발 모드에서 콘솔 로그로 매핑 확인 가능

색상 매핑 예시:
- IP Reputation → #3b82f6 (파란색)
- SQL Injection Protection → #ef4444 (빨간색)
- Common Vulnerabilities → #ec4899 (핑크색)
- Known Bad Inputs → #14b8a6 (청록색)
- Linux Protection → #84cc16 (라임색)
- Unix Protection → #a3e635 (연두색)
- Rate Limiting → #f43f5e (장미색)
- Geo Blocking → #8b5cf6 (보라색)

  - categoryToAttackType 매핑 추가

  - 개발 모드 디버그 로그 추가
- docs/COLOR_MAPPING.md: 색상 매핑 가이드 문서 작성
