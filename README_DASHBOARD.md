# WAF 보안 대시보드

## 개요
Flask 기반의 인터랙티브 웹 대시보드로 WAF 로그 분석 결과를 시각화합니다.

## 주요 기능

### 📊 대시보드 구성

#### 최상단 (3개 차트)
1. **지역별 트래픽** (좌측)
   - 국가별 공격 트래픽 분포를 막대 그래프로 표시

2. **주간 시간대별 공격 현황** (중앙)
   - 요일별, 시간대별 공격 패턴을 라인 차트로 표시
   - 7일간의 24시간 데이터 시각화

3. **월별 공격 유형** (우측)
   - SQL Injection, XSS, CSRF 등 공격 유형별 분포
   - 도넛 차트로 비율 표시

#### 중앙 (2개 카드)
1. **개선 전 룰** (좌측)
   - 위험도별 분포 (HIGH/MEDIUM/LOW)
   - 클릭 시 상세 팝업 표시

2. **개선 후 룰** (우측)
   - 위험도별 분포 (HIGH/MEDIUM/LOW)
   - 클릭 시 상세 팝업 표시

#### 최하단
- **WAF 로그 테이블**
  - 발생일시, 소스IP, 목적IP, HTTP 요청/응답, 공격 유형, WAF 조치
  - 페이지네이션 지원 (20개씩)

### 🔍 팝업 기능

팝업은 화면 우측에서 슬라이드 형태로 등장하며 다음 정보를 포함합니다:

- **룰 이름**: 개선 전/후 룰의 이름
- **위험도**: HIGH/MEDIUM/LOW 배지 + 위험 점수 (0-100)
- **일시**: 룰 생성/적용 일시
- **대상**: IP 주소 / 국가 코드
- **유형**: 공격 유형 이름
- **설명**: 공격 유형 상세 설명
- **원인**: WAF 로그 분석 결과
- **조치 방안**: 적용된 WAF 룰
- **영향도**: 예상되는 영향
- **기대 효과**: (개선 후 룰만) 개선 효과

#### 팝업 네비게이션
- **X 버튼**: 팝업 닫기
- **< 버튼**: 이전 룰 보기
- **> 버튼**: 다음 룰 보기
- **ESC 키**: 팝업 닫기
- **← → 키**: 이전/다음 룰 이동

### 🎨 UI 스타일

- **라이트 모드** (기본)
  - 깔끔한 화이트 톤
  - 미니멀리즘 디자인
  - 통일된 색상 체계

- **다크 모드**
  - 우측 상단 "테마 변경" 버튼으로 전환
  - 눈의 피로를 줄이는 어두운 배경

### 📥 보고서 다운로드

우측 상단의 **"보고서 다운로드"** 버튼을 클릭하면:
- 모든 대시보드 내용을 PDF 형식으로 생성
- 요약 통계, 공격 유형 분포, 룰 요약 포함
- 파일명: `WAF_Report_YYYYMMDD_HHMMSS.pdf`

## 설치 및 실행

### 1. 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. 대시보드 실행
```bash
python report.py
```

### 3. 브라우저 접속
```
http://localhost:5000
```

## API 엔드포인트

| 엔드포인트 | 메서드 | 설명 |
|-----------|--------|------|
| `/` | GET | 메인 대시보드 페이지 |
| `/api/geographic-data` | GET | 지역별 트래픽 데이터 |
| `/api/hourly-attacks` | GET | 시간대별 공격 현황 |
| `/api/monthly-attack-types` | GET | 월별 공격 유형 |
| `/api/rules/before` | GET | 개선 전 룰 목록 |
| `/api/rules/after` | GET | 개선 후 룰 목록 |
| `/api/logs` | GET | 로그 테이블 데이터 (페이지네이션) |
| `/api/rule/<rule_id>` | GET | 특정 룰 상세 정보 |
| `/api/theme` | GET/POST | 테마 설정 |
| `/api/download-report` | GET | PDF 보고서 다운로드 |

## 기술 스택

- **Backend**: Flask 3.0+
- **Frontend**: Vanilla JavaScript, Chart.js
- **PDF 생성**: ReportLab
- **스타일**: CSS3 (CSS Variables for theming)

## Lambda 통합

기존 Lambda 함수와의 호환성을 유지하기 위해 `lambda_handler` 함수가 포함되어 있습니다:

```python
def lambda_handler(event, context):
    # Step Functions에서 호출 가능
    # 분석 결과를 데이터 저장소에 추가
    # 대시보드에서 실시간 확인 가능
```

## 샘플 데이터

테스트를 위해 100개의 샘플 로그와 20개의 샘플 룰이 자동 생성됩니다.
실제 데이터는 Lambda 함수를 통해 추가하거나 API를 통해 직접 추가할 수 있습니다.

## 문제 해결

### 포트 충돌
기본 포트 5000이 사용 중인 경우:
```python
app.run(debug=True, host='0.0.0.0', port=8080)  # 포트 변경
```

### 한글 폰트 문제 (PDF)
PDF에서 한글이 깨지는 경우 시스템 폰트를 등록해야 합니다.
`report.py`의 PDF 생성 부분에 폰트 등록 코드를 추가하세요.
